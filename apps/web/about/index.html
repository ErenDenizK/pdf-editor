Arrange

Pages from every open PDF sit on one light table. Move them between documents and export a file whose bookmarks, links, page labels and form fields follow the pages.

What it does

  • Drag pages between documents; reorder, rotate, delete, duplicate, split, merge and interleave; add images as pages.
  • Rewrites bookmarks and links to the pages' new places and drops the ones whose page was removed; merges form fields and rebuilds page labels.
  • Re-opens the exported file in a fresh PDFium worker and checks it before the download is offered. Export pipeline

What it does not do

  • No conversion from or to Word, Excel or PowerPoint.
  • Every export is a rewrite: signatures in the sources are removed, and the export dialog says so.
  • A tagged-PDF structure that cannot be kept intact is removed, and you are told.

Redact

Redaction removes the text, images and paths under each mark, then re-reads the exported file. A finding blocks the download.

What it does

  • Marks by selection, word, area or search hit, or from the sensitive-data finder: e-mail addresses, phone numbers, IBANs, Turkish ID numbers, card numbers and dates. You review every mark before applying.
  • Applying removes the content under the marks, scrubs matching strings across the file and fills the areas, then checks the exact bytes you will download. Redaction test

What it does not do

  • It does not read inside JBIG2, CCITT or JPEG 2000 images; the report lists them as not searched.
  • The finder suggests matches. It does not decide what is sensitive for you.

Recognise and compare

OCR adds an invisible text layer to scanned pages, so you can search and select their text. Compare shows what changed between two versions.

What it does

  • Recognises nine languages with tesseract.js. Each language pack downloads from this site the first time you use it and can be kept for offline use.
  • Rates each page Good, Review or Poor, and steps through low-confidence words with J and K. On our test scans, 98% of words were found (Chromium). OCR test
  • Compares two documents side by side or as an onion skin, with changed areas, changed words and a report you can export. Compare test

What it does not do

  • OCR is tested on Chromium only so far.
  • Low-confidence words are flagged for you to review, not corrected.
  • Compare is read-only: it shows differences and does not merge them.

Sign and export

Sign with a certificate as the last export step, and see what was checked in a signed file. Edit a line of text, or take pages out as Markdown.

What it does

  • Signs with a .p12 or .pfx certificate as the last export step (PAdES-B), then re-opens the signed file.
  • On open, each signature reads Intact; Intact, changed later; Changed after signing; Broken; or Cannot check, with one line on what was checked. Signature test
  • Edits a line in its own font when the font has the characters, and reads the result back before keeping it; otherwise a bundled font is used and the line is labelled "Font substituted". Text edit test
  • Converts a document, a page or a range to Markdown or plain text, with headings, page breaks and joined hyphens. Markdown test

What it does not do

  • It never labels a signature "valid" or "trusted". It checks the bytes against the certificates in the file; signer identity, trust and revocation are not checked, and there is no long-term validation (LTV).
  • Text edits work one line at a time.
  • Markdown reading order is a heuristic, and tables are not detected.

Check it yourself

  1. Read the Content Security Policy in the app's HTML. It says connect-src 'self': the browser refuses connections to any other origin.

    apps/web/index.html

  2. Watch the status bar. It reads "No external requests" and counts every request to another origin that the browser records (scripts, styles, fonts, images, fetches, workers, WebAssembly). It cannot see WebSocket frames or requests the policy blocked, which never leave the browser.

    external-requests.ts

  3. Open the app once, turn the network off and reload. It still opens a PDF and renders its pages, and the status bar still reads "No external requests".

    offline.spec.ts

  4. Open your browser's network panel and run OCR. The engine and the language pack come from this site, only when you use them; all nine packs with the engine are about 22 MB.

    ADR-0012

  5. No telemetry, no accounts, no cookies. The application panel of your browser's developer tools lists the cookies: there are none.

  6. What stays on your device: the app and its engines in the service worker's cache, the OCR language packs you used or kept, your saved recipes, and settings such as panel layout, language, comment author name, pen presets and the last page read in a document. Your PDFs are not stored; closing the tab closes them. The app's About dialog shows the storage in use.

How it works

The app is static files from this site. Each engine runs in its own Web Worker, reached through messages, so the interface keeps responding while a file renders or exports.

Your edits are recorded as operations in a document model, with undo for every step. Nothing is written into a file until you export. Export assembles a new file, re-opens it in a fresh PDFium worker and checks page count, page sizes and the text under redactions; only then is the download offered.
